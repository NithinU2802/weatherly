# Weatherly

A responsive weather dashboard inspired by the shared reference, built with React, Vite, Tailwind CSS, and shadcn/ui components. It starts with Seattle and uses the free Open-Meteo forecast and geocoding APIs—no API key required.

## Run locally

Requires Node.js 18 or newer. Install dependencies once, then start the Vite development server:

```sh
npm install
npm start
```

Open the local URL printed by Vite (usually [http://localhost:5173](http://localhost:5173)). The app needs an internet connection to retrieve live weather.
